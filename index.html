☘ Klover

Clover helps students learn technical skills consistently, starting with Docker.

How it works

  1. The student picks fixed time windows for practice.
  2. Each window has one task. Clover checks on the student's own laptop that the task was really done.
  3. If a window is missed, a person the student chose, such as a parent or mentor, gets a short WhatsApp message.

Messages and consent

Clover only messages a witness after the witness writes to Clover first to agree. A witness can reply STOP at any time to stop all messages. Messages contain only the missed task and its time window, never browsing history or private content.
